# Hermes Agent Setup

Notes and config for my [Hermes Agent](https://hermes-agent.nousresearch.com/)
install (not the source, which lives at
[NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent)).

## Run official Hermes

```bash
hermes
```

## Files

- `INSTALL_NOTES.md` — install log, issues, open items.
- `hermes-config.yaml` — copy of my non-secret `~/.hermes/config.yaml`
  (secrets stay in `~/.hermes/.env`, never committed).
- `EMERGENCY.md` — how to stop Hermes.
